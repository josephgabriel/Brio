# Brio — Frontend

Interface do Brio: React + TypeScript + Vite + TailwindCSS +
Shadcn UI + TanStack Query.

## Estrutura

- `src/components/ui` — design system genérico (shadcn)
- `src/features/*` — cada funcionalidade do produto (provas, dashboard, sessoes, auth)
- `src/pages` — componentes ligados a rotas
- `src/lib` — cliente HTTP, configuração do TanStack Query, utilidades

Este projeto está na **Etapa 1** do roadmap: apenas a estrutura de
pastas foi criada. `npm create vite` e configuração real acontecem
na Etapa 3.
